Documentação do Projeto — Página Harry Potter
1. Intuito do projeto

O intuito deste projeto é desenvolver uma página web utilizando HTML e CSS, colocando em prática os conhecimentos sobre estruturação de páginas e organização de elementos com CSS Grid.

A atividade também tem como objetivo criar uma página temática sobre Harry Potter, utilizando criatividade na escolha das cores, dos textos e da disposição dos elementos, além de desenvolver uma interface visualmente organizada e agradável.

2. Para que serve o projeto

O projeto serve para apresentar curiosidades, opiniões e informações relacionadas ao universo de Harry Potter de uma maneira simples e visual.

Além disso, ele foi desenvolvido para praticar conceitos importantes do desenvolvimento web, como:

Criação da estrutura de uma página com HTML;

Estilização dos elementos com CSS;

Organização de conteúdos utilizando CSS Grid;

Distribuição de elementos em linhas e colunas;

Aplicação de cores, espaçamentos e bordas;

Criação de um layout organizado e visualmente atrativo.

3. Descrição do projeto

O projeto consiste em uma página web temática com o título “Conheça um pouco dos fatos sobre harry potter de acordo com a visão da duda!”.

A página apresenta diversos cards com frases e opiniões relacionadas aos personagens e acontecimentos da saga Harry Potter, como Hermione, Harry, Gina, Rony, Draco, Sirius Black, Dobby, Cedric e Bellatrix.

No lado direito da página, foi inserida uma imagem relacionada ao universo de Harry Potter, contribuindo para a identidade visual do projeto. Os conteúdos foram organizados em uma área principal, utilizando um layout baseado em CSS Grid.

Também foram utilizadas cores que remetem à temática, como o roxo no cabeçalho, tons de bege nos cards e verde na área da imagem. Ao final, a página possui um rodapé com a mensagem “Agradeço pela visita a minha mente!”.
4. Estrutura da página
1:Cabeçalho (Header)

O cabeçalho está localizado na parte superior da página e contém o título principal do projeto:

“Conheça um pouco dos fatos sobre harry potter de acordo com a visão da duda!”

Ele utiliza um fundo roxo, combinando com a temática de Harry Potter, e possui o texto centralizado.

2:Área de conteúdo (Main)

A área principal ocupa a maior parte da página e contém os cards com as frases e opiniões sobre Harry Potter.

Os cards estão distribuídos em três colunas, formando várias linhas. Cada card possui uma cor bege, bordas arredondadas e texto centralizado.

Essa organização é feita com o auxílio do CSS Grid, que permite distribuir os elementos de maneira uniforme.

3:Área lateral / Imagem

No lado direito da página existe uma área destacada com fundo verde, contendo uma imagem relacionada ao universo de Harry Potter.

Essa seção complementa o conteúdo principal e contribui para a aparência temática do projeto.


4:Rodapé (Footer)

O rodapé está localizado na parte inferior da página e contém a mensagem:

“Agradeço pela visita a minha mente!”

Ele possui fundo preto, texto branco e serve para finalizar a estrutura da página.

5. Tecnologias utilizadas

HTML5: utilizado para criar a estrutura da página e seus elementos.

CSS3: utilizado para definir as cores, tamanhos, espaçamentos, bordas e alinhamentos.

CSS Grid: utilizado para organizar os cards e as áreas do layout em linhas e colunas.

6. Conclusão

A realização deste projeto permitiu colocar em prática os conhecimentos de HTML e CSS, principalmente o uso do CSS Grid para organizar os elementos de uma página.

A criação da página temática sobre Harry Potter também possibilitou trabalhar com cores, imagens e organização visual, resultando em uma interface simples, criativa e estruturada.

Com essa atividade, foi possível compreender melhor como o CSS Grid facilita a criação de layouts e como ele pode ser aplicado em diferentes tipos de páginas web.
